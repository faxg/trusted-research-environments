# References

## Quick Reference

This page provides quick links and references for working with TREs.

## Glossary

**TRE (Trusted Research Environment)**
: A secure computing environment for analyzing sensitive data

**Data Controller**
: The entity that determines the purposes and means of processing personal data

**Data Processor**
: The entity that processes data on behalf of the data controller

**GDPR (General Data Protection Regulation)**
: EU regulation on data protection and privacy

**HIPAA (Health Insurance Portability and Accountability Act)**
: US legislation for data privacy and security in healthcare

**ISO/IEC 27001**
: International standard for information security management systems

**Federated Analysis**
: Analyzing data across multiple locations without moving the data

**Data Egress**
: The process of removing data or results from a TRE

**Workspace**
: An isolated computing environment within a TRE
