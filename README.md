# Trusted Research Environments

A collection of material, links and other assets around trusted and confidential research environments (TRE).

## 📚 Documentation

Visit the documentation site: [https://faxg.github.io/trusted-research-environments/](https://faxg.github.io/trusted-research-environments/)

## 🚀 Quick Start

### Local Development

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Serve the documentation locally:
   ```bash
   mkdocs serve
   ```

3. Open your browser at `http://localhost:8000`

### Using GitHub Codespaces or VS Code

This repository includes a devcontainer configuration for easy development:

1. Open in GitHub Codespaces or VS Code with Remote Containers extension
2. The environment will automatically install all dependencies
3. Run `mkdocs serve` to start the development server

The devcontainer includes:
- Python environment with MkDocs
- Markdown extensions (Markdown All in One, Mermaid diagrams)
- Spell checker
- YAML support
- Draw.io integration
